FAQ

Common questions

Something else? Contact our team.

Does it work with my tech stack?

Yes, if your product runs in a browser. QA Automation tests the rendered app the way a real user sees it, so it does not matter whether the backend is written in JavaScript, Python, PHP, Java, C#, Ruby, Go or anything else.

Can it test pages behind a login?

Yes. Add login steps once and every scan signs in first. Passwords are read from environment variables, so they never live in your config file.

Do I need to write code?

No. A scan only needs a URL. User flows are written as simple steps like "click", "fill" and "expect text", with no programming required.

Can I run it in my CI pipeline?

Yes. It runs from the command line, returns a failing exit code when critical issues are found and saves the report as a build artifact.
